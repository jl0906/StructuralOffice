# Security Policy

## Supported versions

HomeCurator is currently in alpha. Security fixes are provided only for the most
recent published build.

## Reporting a vulnerability

Use private vulnerability reporting under **Security → Report a vulnerability**
in the GitHub repository. Do not publish sensitive details in a public issue.

Include the affected version, expected and actual behavior, potential impact,
and reproduction steps when possible. Do not submit Home Assistant configuration
files, tokens, or diagnostic archives containing personal or secret data.
